# 🔐 Python Password Generator with Flask Frontend

A simple and secure **Password Generator** built with **Python** and **Flask**, with a **frontend in HTML, CSS, and JavaScript**. Users can select password length and types of characters to include (lowercase, uppercase, digits, special characters) and generate strong, random passwords instantly.

---

## ⚡ Features

- Select password length (4-128 characters)
- Choose character types:
  - Lowercase letters
  - Uppercase letters
  - Digits
  - Special characters
- Secure random password generation using Python `secrets` module
- Frontend interface using HTML, CSS, JS
- Instant password display
- Error handling with emoji notifications

## 💻 Usage

1. Enter the **desired password length**.
2. Check/uncheck the boxes for **lowercase, uppercase, digits, and special characters**.
3. Click **Generate Password**.
4. Copy your password and use it securely.
